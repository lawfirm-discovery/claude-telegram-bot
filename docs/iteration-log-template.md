# ERP 메뉴 검증 반복(Iteration) 로그 템플릿

> **용도**: 매 검증 반복마다 발견한 이슈, 수정 사항, 개선점을 기록하는 표준 템플릿.
> **작성일**: 2026-05-10
> **파일 명명**: `reports/{전문가타입}-iter{N}-{YYYYMMDD}.md`

---

## 사용법

1. 새 반복 시작 시 이 템플릿을 복사하여 `reports/` 폴더에 저장
2. 헤더의 메타데이터를 채움
3. 각 섹션을 순서대로 기록
4. 반복 종료 시 요약 통계 작성
