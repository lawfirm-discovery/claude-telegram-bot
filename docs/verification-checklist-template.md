# ERP 메뉴 통합 검증 체크리스트 템플릿

> **용도**: 전문가 타입별 ERP 메뉴 검증 시 매 반복(iteration)마다 사용하는 표준 체크리스트.
> **작성일**: 2026-05-10
> **적용 대상**: 모든 전문가 타입 (변호사, 세무사, 변리사, 법무사, 회계사, 관세사, 감정평가사, 행정사, 노무사, 공증인, 속기사)

---

## 사용법

1. 새 전문가 타입 검증 시작 시 이 템플릿을 복사하여 `docs/verification-{타입명}-{날짜}.md` 로 저장
2. 각 메뉴 페이지별로 Section A~D 를 순회하며 체크
3. 결과는 `iteration-log-template.md` 에 기록

## 결과 집계 방법

각 항목의 결과 컬럼에 다음 중 하나를 기록:

| 마커 | 의미 |
|------|------|
| PASS | 검증 통과 |
| FAIL | 결함 발견 — 이슈 ID 기록 |
| SKIP | 해당 없음 또는 이번 반복에서 미검증 |
| STUB | 스텁/목업 구현 — 후속 작업 필요 |
| N/A | 해당 메뉴에 적용되지 않는 항목 |

### 통과율 계산

```
통과율 = PASS / (PASS + FAIL) * 100%
커버리지 = (PASS + FAIL) / (전체 - N/A) * 100%
```
